# Reinhartsen Eiendom AS - Netlify-versjon

Denne pakken inneholder:
- ferdig nettside
- kontaktskjema via Netlify Forms
- CMS via Decap CMS

## Slik tar du den i bruk

1. Opprett en GitHub-repo
2. Last opp alle filene i denne pakken
3. Logg inn på Netlify og importer repoet
4. Når siden er publisert:
   - gå til Site configuration -> Identity og aktiver Identity
   - aktiver Git Gateway
   - inviter deg selv som bruker i Identity
5. Gå til /admin/ på nettsiden for å logge inn i CMS
6. Legg inn og rediger eiendommer der

## Kontaktkjema
Skjemaet er satt opp med Netlify Forms.
Meldinger kommer inn i Netlify under Forms.

## Viktig
Bytt ut kontaktinformasjon i index.html:
- e-post
- telefon
- adresse
